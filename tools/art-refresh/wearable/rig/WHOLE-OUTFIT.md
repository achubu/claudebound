# Design a whole outfit, deliver separate gear

The shared design source can now be four registered COMPLETE OUTFIT views. The actor itself remains immutable. This workflow is an extraction aid using reviewed slot masks, not arbitrary AI segmentation of an unregistered concept picture. No new armor art is generated by this tooling change.

1. Generate reference kit:

       python3 tools/art-refresh/wearable/rig/split_outfit.py --guides --out /tmp/outfit-guide

   It contains the actual canonical idle actor in each direction, slot guides and a generation prompt. Use matching 256x256 poses/positions; never accept a replacement actor as the game base. Design all six pieces consistently in these four images.

2. Split the visible equipment:

       python3 tools/art-refresh/wearable/rig/split_outfit.py --views front.png left.png right.png back.png --out /tmp/my-set

   Slot ownership follows game draw order. Only each slot's visible pixels are extracted into the existing directional part-cell format. Original foreground hands/device/head are excluded where appropriate. Isolated parts are trimmed and padded with transparent gutters, preserving aspect ratio.

3. Inspect outfit.json and the *-missing.png masks. They identify REQUIRED material not visible in the shared outfit: waistband behind belt, legs under boot tops, etc. The tool never invents those pixels. Supply independent aligned underlayer drawings or masked edits. JSON maps slot to four registered patch PNG paths, relative to the JSON file:

       {"pants":["down.png","left.png","right.png","up.png"]}

       python3 tools/art-refresh/wearable/rig/split_outfit.py --views front.png left.png right.png back.png --underlayers underlayers.json --out /tmp/my-set

   Patch pixels are used ONLY in that slot's hidden region. A missing-pixel count of zero means coverage, not visual approval. Concept regions and underlayers still need human review, especially around overlaps and thin seams.

4. After coverage AND visual review, prepare each slot with its generated atlas:

       python3 tools/art-refresh/wearable/rig/prepare_gear.py --atlas /tmp/my-set/boots/source-atlas.png --slot boots --look cyber-boots --items boots,cloudstepBoots --out /tmp/my-boots --audit-outfits

   Use the correct item IDs/look names for the other five slots. The existing fitter produces all 36 frames, clean patch, manifest and final compositor proofs; its foreground pass preserves the original actor. Claude imports approved handoffs with wearable_add.py.

The splitter never marks anything production-ready. Incomplete visible-only pieces must not be shipped as complete garments. A full-outfit image cannot reveal concealed material, and these masks cannot reliably understand arbitrary new silhouettes or asymmetric limbs. Those require reviewed calibration/source art. Game code, runtime assets and movement are untouched.
